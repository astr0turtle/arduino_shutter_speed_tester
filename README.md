Arduino sketches for a BPW34 silicon PIN photo diode based shutter speed tester. 

analog_voltage_check.ino - Test code to connect the photo diode to an analog pin to see the actual voltage levels for testing.

arduino_digital_input_pin_check.ino - Test code to output the state of pin D2 on the Arduino IDE serial console.

arduino_shutter_speed_tester.ino - Code for the shutter speed timer. You will first need to install the Adafruit SSD1306 library in the Arduino IDE for the program to work.
